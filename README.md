# ЖК 4U — демо Telegram Mini App

Кабінети мешканця і ЖЕКу для житлового комплексу 4U (вул. Ак. Булаховського, 2, Київ).

- **/** — кабінет мешканця
- **/admin/** — кабінет керуючої компанії

Це демо: дані вигадані, все працює без сервера. Заявки, повідомлення асистенту,
призначення майстрів обробляються прямо у вашому браузері й нікому не видні.
Перезавантаження сторінки повертає початковий стан.
